# 银行电话营销客户转化分析（UCI Bank Marketing）

## 4. 数据处理要点

| 环节    | 处理策略                                                       | 依据                                                                        |
| ----- | ---------------------------------------------------------- | ------------------------------------------------------------------------- |
| 重复值   | 删除完全重复记录（原始层 0 条）                                          | 完全重复意味着同一通电话被记录两次，会虚增触达量                                                  |
| 无效记录  | 剔除 `duration = 0` 的 3 条                                    | 通话时长为 0 表示未接通，不构成营销接触                                                     |
| 业务性缺失 | `unknown` 保留并生成 `*_known` 指示变量                             | `poutcome=unknown` 占 81.8%（首次触达客户本就没有历史活动），删除会系统性丢失新客；打标后模型可区分"未知"与"真实类别" |
| 异常值   | `duration` / `balance` 按 P99 / P1 缩尾，原始值保留                 | 通话时长最大 4,918 秒、余额跨度 −8,019 ~ 102,127，极端值会主导均值与聚类距离                        |
| 日期重建  | 依据 UCI 说明（2008-05 至 2010-11）与月份连续区块，按"月份回退即跨年"重建年份         | 原始数据只有 `day` + `month`，没有年份；重建后共 30 个月、133 周，与官方区间一致                      |
| 类型统一  | 数值字段强类型、类别字段去空格并小写、月份映射为序号                                 | 避免 `"May"` / `"may"` 被当作两类                                                |
| 派生指标  | 是否认购、通话分钟、余额分层、年龄段、联系次数分档、是否有历史联系、渠道中文名                    | 支撑漏斗、分群、热力图等分析                                                            |
| 多表对齐  | 主表按 `year_month` 统一时间轴；辅助表只做加载阶段的完整性核对（行数/字段数/MD5），不并入主表 | 两表无客户主键、行数不同（41 188 行为剔除缺失值后的子集），强行拼接会引入口径误差；宏观指标仅作背景解释 |

## 5. 分析模型（7 个）

| 编号    | 模型               | 业务问题            | 关键参数/阈值依据                                     | 主要输出                             |
| ----- | ---------------- | --------------- | --------------------------------------------- | -------------------------------- |
| M1    | 描述性统计与结构分析       | 谁在被触达？结构是否失衡？   | 分组口径：触达量、认购量、转化率、时长、余额                        | `eda_*.csv`、fig02–fig08          |
| M2    | 漏斗转化分析           | 客户在哪一层流失？       | 接通 ≥30s（行业接通判定）；有效沟通 ≥120s≈P25；深度沟通 ≥300s≈P75 | `funnel_overall.csv`、fig16、fig10 |
| M3    | 环比/同比 + 移动平均     | 增长质量如何？季节节奏是什么？ | MoM 用月度环比、YoY 用同月对比、MA3 平滑短期波动                | `trend_monthly.csv`、fig17        |
| M4    | 帕累托/ABC 分类       | 贡献是否集中？资源该给谁？   | 累计认购占比 70% / 90% 分界（经典 ABC 口径）                | `pareto_segment.csv`、fig19       |
| M5    | 波士顿矩阵            | 客群组合应如何取舍？      | 相对份额 1.0（均值）；增速分界取客群中位数（全部客群同比为正，用 0 会退化为单象限） | `bcg_job.csv`、fig18              |
| M6    | K-Means 客群分群     | 有哪些可运营的客群？      | 9 维特征 Z-Score；k 由轮廓系数 + 业务可解释性共同确定（k=5）       | `kmeans_profile.csv`、fig20/21    |
| M7    | 关联规则（Apriori 思想） | 哪些特征组合显著提升认购？   | 最小支持度 1%、最小置信度 20%、提升度 ≥1.2                   | `apriori_rules.csv`、fig22        |
| M4-预测 | SARIMA           | 未来 8 周认购量？      | (p,1,q) 按 AIC 网格选阶；留出最后 12 周回测；95% 置信区间       | `forecast_weekly.csv`、fig23/24   |

预测回测同时给出 **MAPE / RMSE / MAE**，并与 Holt 阻尼趋势、朴素基线（近 4 周均值）对比，避免"只报模型不报误差"。

## 7. 交互式大屏

`python scripts/06_dashboard.py` 生成 `outputs/dashboard/dashboard.html`，深色主题，**12 个组件**：

| # | 组件 | 类型 | 交互 |
|---|---|---|---|
| 1–6 | KPI 指标卡 ×6（触达 / 认购 / 转化率 / 平均时长 / 覆盖职业 / 峰值月） | 指标卡 | 随渠道筛选实时刷新 |
| 7 | 月度触达与转化 | 双轴组合图 + dataZoom | 缩放、十字准星、三图联动 |
| 8 | 渠道认购结构 | 环形图 | 悬停显示人数与占比 |
| 9 | 客群转化率 | 横向条形图 | **点击下钻**客群漏斗 |
| 10 | 营销漏斗 | 漏斗图 | 悬停显示累计/层内留存率，随下钻刷新 |
| 11 | 月份 × 客群转化 | 热力图 | 悬停明细、颜色映射 |
| 12 | 客群明细表 | 数据表 | **点击行下钻**、转化率条形对比 |

三层联动：① 顶部「联系渠道」下拉切换 全部/手机/座机，全部组件同步重算；② 点击客群条形或明细行，漏斗切换为该客群独立漏斗；③ `echarts.connect()` 把趋势图、客群图、热力图绑定，轴指示器与缩放同步。

> 技术路线：Python 负责取数与聚合、ECharts 负责渲染与交互。**不依赖 pyecharts**，脚本运行时会把 `echarts.min.js`（约 1 MB）缓存到 `outputs/dashboard/`，因此大屏可完全离线打开；若下载失败会自动回退到 jsDelivr / unpkg / BootCDN 三个 CDN 源。
