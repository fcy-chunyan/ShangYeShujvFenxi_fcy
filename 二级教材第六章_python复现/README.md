# 第六章 Python 复现

本目录按教材附件的两个子目录分别复现《CDA 二级认证教材：量化策略分析》第6章内容。两个脚本默认直接读取教材附件目录中的原始数据，不需要复制输入文件。

## 抽样

```powershell
.\.venv\Scripts\python.exe ".\二级第六章-市场调研与数据预处理\1数据采集与处理 1 数据采集方法\6_1sampling.py"
```

复现简单随机、Dist 分层、等距系统抽样的固定数量与 10% 比例方案，使用固定随机种子，默认值为 42。结果写入 `1数据采集与处理 1 数据采集方法\复现结果`。

## 数据预处理
