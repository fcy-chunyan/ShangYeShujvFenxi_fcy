## 二、合规性说明（对照作业要求 2.1）

1. **非爬虫**：数据通过数据源官方提供的一次性下载文件获取，**全流程未使用** Scrapy、Selenium、requests + 网页解析、模拟登录等任何网页抓取技术，也未绕过任何访问限制。
2. **白名单来源**：UCI 开放数据平台属于作业附件 A 推荐的公开数据源（"UCI / Kaggle"条目），获取方式为"官方下载"。
3. **数据规模**：主表 45,211 条，清洗后 45,208 条，满足"主表记录数不少于 500 条"的要求；数据量适中，**全量使用未抽样**，因此不存在抽样方法说明问题。
4. **隐私与伦理**：数据集由 UCI 匿名化后公开发布，不含姓名、身份证号、电话号码、地址等个人身份信息（PII），分析对象为"一次外呼接触"而非自然人，不存在个人信息泄露风险。
5. **可复现**：原始文件只读保存在 `data/raw/`，MD5 记录于 `data/raw/schema.json`；清洗结果导出为 CSV / JSON / SQLite 三种格式，任何人均可核验中间结果。

## 三、数据使用限制与注意事项

- `duration`（通话时长）是**事后变量**：只有通话结束后才知道其取值，且在原始论文中被证实是最强预测变量。因此本项目仅将其用于"事后归因与漏斗分层"，**不将其作为上线预测模型的输入特征**，避免"数据穿越"。
- 数据时间为 2008-05 至 2010-11，距今较久，宏观环境（利率、监管、通信方式）已变化，结论适用于方法论演示与相对比较，不宜直接外推为当前营销效果。
- 数据集为葡萄牙零售银行，客群文化与国内银行存在差异，商业建议需结合本地实际调整。
